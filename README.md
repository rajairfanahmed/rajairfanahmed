## 🚀 Featured Project

### 💳 Advanced Subscription & Membership Platform (Final Year Project)

A full-stack membership platform for creators and subscribers. Creators publish gated videos, articles, and files. Subscribers follow a creator for free, or pay that creator for Basic or Premium access through Stripe Checkout. Admins oversee users, content, payments, and platform settings.

#### ✨ Features
- 💳 Stripe-powered subscription billing
- 🔐 Role and tier-based access control (Clerk)
- ☁️ Cloudflare R2 file storage
- 📊 Membership and usage dashboards
- 📁 Per-creator Free / Basic / Premium access
- ⚡ REST API architecture built on Next.js 15

🔗 **Project Repository:** https://github.com/rajairfanahmed/fyp-advanced-subscription-and-membership-platform
