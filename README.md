## Featured project

### Advanced Subscription &amp; Membership Platform

**Capstone / Final Year Project** — a full-stack membership product for creators and subscribers.

Creators publish gated video, articles, and files. Subscribers follow a creator for free, or purchase **that creator’s** Basic or Premium plan through Stripe Checkout. Admins oversee users, content, payments, and platform settings.

Membership is **per creator**, not a single site-wide plan. Billing uses the platform Stripe account (Checkout, Customer Portal, and signed webhooks). Access is stored against each subscriber–creator pair.

**[View repository](https://github.com/rajairfanahmed/fyp-advanced-subscription-and-membership-platform)**

| | |
|---|---|
| **Stack** | Next.js 15, React 19, TypeScript, Tailwind CSS |
| **Auth** | Clerk (email, Google, verification, password reset) |
| **Data** | PostgreSQL — 17 tables |
| **API** | Next.js App Router — 50+ route handlers |
| **Billing** | Stripe Checkout, Billing Portal, webhooks |
| **Storage** | Cloudflare R2 (video, covers, PDF / ZIP / RAR) |
| **Roles** | Subscriber, creator, and admin allowlist |

**Capabilities**
- Per-creator Free / Basic / Premium access
- Role-based routes and admin oversight
- Recurring billing with grace period and cancel-at-period-end
- Object storage with attachment downloads (files do not open in-tab)
- In-app notifications and membership / usage dashboards
